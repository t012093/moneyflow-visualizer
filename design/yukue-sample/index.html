    制度をさがす

    立場をえらぶと、関係のある制度だけが残ります。自分が対象になるかどうかは、そのままAIに確認できます。

    金額や状態にはサンプルの値が含まれます。申請の前に、担当省庁のページで最新の条件を確認してください。

    コネクター（MCP Apps）

    いつものAIから、そのまま聞ける

    ゆくえをClaudeやChatGPTにつなぐと、会話の中で国のお金の流れを調べられます。対応するアプリでは、図も会話の中にそのまま表示されます。

    つなぎ方（Claudeの場合）

    1. Claudeの「設定」から「コネクタ」を開く
    2. 「カスタムコネクタを追加」をえらび、下のURLを貼る
    3. 会話で「ゆくえで調べて」と頼む
    https://mcp.yukue.example/mcp

    公開されている情報だけを扱うので、ログインは要りません。ChatGPTなど、同じ規格（MCP Apps）に対応したAIにも同じサーバーでつなげる想定です。URLは見本です。

    このサンプルの考え方

    設計メモ

    なぜこの形にしたか、情報をどう集めてつなぐか、AIとどうつなぐかをまとめています。

    ねらい

    情報が省庁ごとにバラバラ
    「お金の流れ」を背骨にして、政策・法律・制度・ニュースをすべてそこに結びつける。どの入口から入っても、同じ項目にたどり着く。
    政策や制度の動きがXで流れていくだけ
    毎日、各省庁・国会・官報などの一次情報から集め、「種類」と「いまの段階」をそろえて並べる。Xは話題のきっかけとして扱い、根拠にはしない。
    見るだけで終わってしまう
    どの画面からでもAIに聞ける。答えには出典が付き、画面の図も一緒に動く。外のAI（Claudeなど）からも同じ情報を呼び出せる。

    お金の流れの見せ方

    • 左から右へ、一本の流れ「どこから来て、どこへ行くか」を1枚に。帯の太さがそのまま金額なので、数字を読まなくても大小が分かる。
    • 最初は少なく、押すと深く最初に見せるのは3列・十数本だけ。行き先を押すと内訳、その先の届け先へ進む。数千の事業を一度に並べない。
    • 兆円を、自分の大きさに「1人あたり」「1万円のうち」に切り替えられる。122兆円は想像しにくくても、1万円のうちの3,000円なら分かる。
    • 色は分野に固定する社会保障は青、防衛は黄。図でも、動きの一覧でも、チャットの答えでも同じ色を使う。絞り込んでも色は変わらない。
    • 混ざるお金は、混ぜて描く税金と国債は一般会計でひとつになる。「消費税がそのまま防衛費へ」のような、実際にはない線は引かない。
    • 数字には出典と段階を付ける当初予算か、補正後か、執行済みか。どの資料のどの段階の値かを示す。図と同じ内容を表でも出す。

    毎日の収集のしくみ

    集める（毎日・定時）

    • APIがあるものは定時に取得（法令、国会、補助金、法人情報など）
    • CSV・Excelは更新を検知して取り込む（事業ごとの予算と支出先など）
    • PDFや新着ページは差分を拾い、AIで構造化する（予算書、各省の発表）

    つなぐ

    • 資料ごとにちがう単位（円・千円・億円）と時刻をそろえる
    • AIが種類・分野・段階を判定し、短い要約を作る
    • 事業番号・法令番号・法人番号でお金の流れに結びつける
    • 自信が低いもの、金額が大きいものは人が確認してから公開

    届ける

    • アプリの流れ図・動きの一覧・制度さがし
    • AIチャット（アプリ内）とコネクター（外のAI）
    • フォロー中のテーマに動きがあれば通知

    おもな情報源は次のとおりです。いずれも国の機関が公開しているものです。事業レビューの集計額は予算書の金額と一致しないため、別の基準の数字として並べて示します。

    AIとコネクター

    「Claudeの画面に自社のアプリを出せる」仕組みは、MCP Apps です。AIと外部サービスをつなぐ規格（MCP）の公式拡張として、2026年1月に公開されました。道具（ツール）にHTMLの画面を結びつけておくと、Claudeがそれを会話の中の安全な枠に表示します。開発には @modelcontextprotocol/ext-apps を使います。

    Claudeでは「インタラクティブコネクタ」として、Web・デスクトップ・スマホアプリで表示されます。Claude Code は道具を呼べますが、図は描画しません。そこで、MCPサーバーを1つ作り、3つの出口で使い回す構成にします。

    外のAIから（コネクター）
    ClaudeやChatGPTにURLで追加する。公開データだけなので認証なしで提供できる。公式ディレクトリに載せるには、全ツールへの読み取り専用の明示、プライバシーポリシー、画面写真などが必要。
    アプリの中で（AIチャット）
    Claude APIが、MCPコネクター経由で同じ道具を呼ぶ。図は会話に埋め込まず、アプリ自身の画面を動かす。このサンプルの「AIに聞く」がその形。
    開発者・Claude Code から
    同じサーバーにつなぐと、結果がテキストで返る。記事の下調べや分析の自動化に使える。
