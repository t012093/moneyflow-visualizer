# 放課後児童クラブ関係予算の支援内容とお金の流れ

## 結論

- 2025年度の放課後児童クラブ関係予算は、家計への現金給付ではなく、クラブの運営、施設整備、研修、DX実証、巡回支援を支える予算として整理されている。
- 基本の流れは、こども家庭庁から自治体へ交付・補助が入り、その先で公営クラブの運営費、委託運営主体、工事、システム導入、巡回支援の委託先などへ支出される構造である。

## 主要な予算項目

- 放課後児童クラブ（運営費・処遇改善）: `1,209億円`
- 放課後児童クラブ（施設整備）: `143億円`
- 放課後児童クラブ（研修関係）: `29億円`
- 放課後児童クラブ（DX推進実証）: `1.1億円`
- 放課後児童クラブ（巡回等サポート）: `11億円`
- 放課後児童クラブ等におけるICT化推進事業: `2,431億円の内数`

## 事業ごとの見方

### 運営費・処遇改善

- `子ども・子育て支援交付金` として整理され、放課後児童クラブの運営費、放課後児童支援員の処遇改善、障害児受入加配、送迎支援などを支える。
- お金の流れは、こども家庭庁から自治体へ入り、その先で公営クラブの運営費、または民間運営主体への委託・補助に向かう理解が自然である。

## 運営費・処遇改善の出口モデル

- 主体別の厳密な執行額一覧は確認できていない。
- ただし、こども家庭庁の `令和7年 放課後児童健全育成事業（放課後児童クラブ）の実施状況` では、クラブ数の運営主体別内訳が確認できる。
- このためアプリでは、`1,209億円` の reviewed 事業額をそのまま残しつつ、出口は `クラブ数シェア` を比率根拠とする model-based second hop として可視化する。
- さらに `公立民営` と `民立民営` については、同じ一次資料の運営主体別クラブ数を使って third hop まで分解している。

### 主な出口

- 公立民営: `13,543か所 / 52.2%`
- 民立民営: `6,585か所 / 25.4%`

### 民立民営の主な運営主体

### 施設整備

- `子ども・子育て支援施設整備交付金` として整理され、既存施設を活用した改修、新たなクラブ実施のための環境整備、アパート等活用費を含む。
- 運営費ではなく、箱を作る、増やす、改修するための資本的支出に近い。

## 施設整備の出口モデル

- 施設整備についても、主体別の厳密な執行額一覧は確認できていない。
- ただし、こども家庭庁の `令和7年度 こども・子育て支援関係予算のポイント` では、公立整備と民間整備で設置主体と補助率が分かれている。
- このためアプリでは、`143億円` の reviewed 事業額をそのまま残しつつ、出口は `公立主体` と `民間主体` の二系統に分けて可視化する。
- ただし公立・民間の配分比率そのものは公表されていないため、`令和7年実施状況` のクラブ数シェアを proxy にした model-based second hop として扱っている。

### 主な出口

- 公立主体整備: `19,343か所 / 74.6%` を proxy
- 民間主体整備: `6,585か所 / 25.4%` を proxy

### 公立整備ルート

- 設置主体: `市町村`
- 補助率（嵩上げ前）: `国1/3・都道府県1/3・市町村1/3`
- 補助率（待機児童市町村等の嵩上げ後）: `国2/3・都道府県1/6・市町村1/6`
- 公立として扱われる条件は、`市町村が設置主体` であること。PFI 等で整備して後に市町村が買い取る方式も、このルートに含まれる。

### 民間整備ルート

- 設置主体: `社会福祉法人、学校法人、市町村が認めた者等`
- 補助率（嵩上げ前）: `国2/9・都道府県2/9・市町村2/9・社会福祉法人等1/3`
- 補助率（待機児童市町村等の嵩上げ後）: `国1/2・都道府県1/8・市町村1/8・社会福祉法人等1/4`

### 具体例（公式協議一覧で確認できる受給先）

- ここでいう `受給先` は、国から直接ではなく、`子ども・子育て支援施設整備交付金` の協議対象として公式資料に載っている整備対象施設・団体のことを指す。
- 千葉県の `令和7年度子ども・子育て支援施設整備交付金協議施設一覧` では、公立ルートと民間ルートの具体例が確認できる。

#### 公立ルートの例

- 船橋市 `中野木第2放課後ルーム` `大規模修繕`
- 松戸市 `稔台放課後児童クラブ1/2` `創設`
- 柏市 `柏市立光ケ丘小こどもルーム第三保育室/第四保育室` `創設`
- 八千代市 `八千代台学童保育所A/B/C` `改築`
- 鎌ケ谷市 `西部小学校第1放課後児童クラブ` `大規模修繕`

#### 民間ルートの例

- `館山学童クラブA-D` `シダックス大新東ヒューマンサービス株式会社`
- `上野小学校放課後ルーム` `シダックス大新東ヒューマンサービス株式会社`
- `勝浦小学校放課後ルーム1/2` `シダックス大新東ヒューマンサービス株式会社`
- `学童クラブ レインボーキッズ(1)(2)` `保護者会`
- `学童クラブ アゼリーアカデミア千葉ニュータウン` `学校法人アゼリー学園`
- `学童クラブめぐみ(1)(2)` `社会福祉法人佐原めぐみ会`

- したがって、民間ルートの実際の受け皿は `株式会社系受託事業者・保護者会・学校法人・社会福祉法人` などで、公立ルートでは `市町村直営の放課後ルーム・こどもルーム・学童保育所` が確認できる。

## 施設整備の創設で使える費用

- `創設` は、新たに放課後児童クラブ施設を整備することを指す。
- 対象経費には、`本体工事費`、`工事請負費`、`工事事務費`、`特殊附帯工事費` が含まれる。
- `既存建物の買収費` も、新築より効率的と認められる場合は対象になりうる。
- `賃借料加算` は、新たに土地を借りて整備する場合などに設定されている。
- `校内交流型`、`過疎・山村・離島等` では、条件付きで加算措置がある。

## 創設で対象外になる費用

- `土地買収費`
- `整地費`
- `職員宿舎`
- `門・囲障・構内雨水排水・構内通路` などの外構
- その他、施設整備費として不適当とされる費用

## 創設の主な要件

- 公立ルートでは `市町村が設置主体`、民間ルートでは `社会福祉法人・学校法人・公益法人・その他市町村が認めた者` が設置主体になる。
- 専用区画は `児童1人あたりおおむね1.65㎡以上` が必要で、開所時間中は原則専用利用とされる。
- 支援の単位ごとに `2人以上` の職員配置が必要で、`1人以上` は放課後児童支援員とされる。
- 支援の単位は原則 `おおむね40人以下`。
- 待機児童解消のための嵩上げは、`創設` または `定員増を伴う整備` で、待機児童が既にいるか発生見込みがある市町村が前提になる。
- `校内交流型` は、小学校敷地内等で放課後子供教室と一体的に実施し、市町村計画に受け皿整備量があり、余裕教室活用が困難で、待機児童があるか発生見込みがある場合に対象となる。

### 研修関係

- `こども政策推進事業費補助金（放課後関係） 29億円` のページで明示されているのは、`放課後児童支援員認定資格研修事業` と `放課後児童支援員等資質向上研修事業` である。
- したがって、アプリで以前 `DX・体制強化 29億円` としていたものは、厳密には `研修関係 29億円` と読むのが正確である。

#### 研修関係の出口モデル

- `認定資格研修` は、`都道府県・指定都市・中核市` が実施主体で、市町村や民間団体等へ一部委託可能。
- `資質向上研修` は、`都道府県又は市町村` が実施主体で、民間団体等へ全部又は一部委託可能。
- ただし、`29億円` の中でこの2研修にいくらずつ配分されるかは公表されていない。
- そのためアプリでは、まず `認定資格研修 / 資質向上研修` の2本に均等按分する model-based second hop として可視化している。

#### 研修関係の third-hop

- `認定資格研修` の先は、`実施主体（都道府県・指定都市・中核市）` と `受託事業者` の2系統で見るのが自然。
- `資質向上研修` の先は、`実施主体（都道府県又は市町村）` と `受託事業者` の2系統で見るのが自然。
- ただし、自治体がどれだけ直営で持ち、どれだけ委託に出しているかの金額比率は公表されていない。
- そのためアプリでは、third-hop は `実施主体 / 受託事業者` の二系統を均等按分する model-based 表示にしている。

#### 自治体の公表例

- `東京都` の認定資格研修は、都が実施主体で、運営業務を `株式会社東京リーガルマインド` に委託している。
- `山口県` の認定資格研修は、`特定非営利活動法人学童保育協会` を委託先として公表している。
- `新潟県` では、認定資格研修・資質向上研修の両方について `株式会社東京リーガルマインド` が受託先として確認できる。
- `千葉県` や `福島県` でも、資質向上研修を含む委託仕様書・公募資料が公表されており、委託ルート自体は公式資料で確認できる。

### DX推進実証

- `放課後児童クラブ利用手続き等に関わるDX推進実証事業（仮称）` は、`1.1億円` の別建て事業として確認できる。
- 実施主体は `市町村` で、`国10/10`、`1自治体あたり 10,574千円`。
- 内容は、利用申請のオンライン化、利用調整、事業所と自治体の情報連携、保護者連絡、請求、出欠管理、育成支援記録などをつなぐ総合的なDX実証である。
- 公式資料では、`市町村・放課後児童クラブ運営法人/事業所・開発ベンダー` で構成するコンソーシアムを設置するとされている。
- ただし、`1.1億円` の費目別内訳は公表されていないため、アプリではこの3者を均等按分する model-based second hop として可視化している。

### ICT化推進

- `放課後児童クラブ等におけるICT化推進事業` は、`2,431億円の内数` として示されているため、放課後児童クラブ向けの厳密な額までは切れない。
- ただし、補助単価として、`システム導入 1か所あたり 50万円`、`翻訳機等の購入 1か所あたり 15万円` が示されている。
- この事業は、職員の業務負担軽減、保護者連絡、オンライン研修、多言語対応などの利用環境整備を支える。

### 第三者評価・利用調整支援

- `放課後児童クラブ第三者評価受審推進事業` と `放課後児童クラブ利用調整支援事業` は、`1,209億円` の運営費等の並びで確認できる。
- ただし、この2事業だけの個別金額は資料上では切れていない。

### 巡回等サポート

- `保育対策総合支援事業費補助金` として整理され、要支援児童等対応推進、育成支援体制強化、巡回アドバイザー配置などを支える。
- 現場の困難ケース対応や伴走支援のための予算で、自治体直営配置か外部委託かは地域の実施方法によって変わる。

## 制度の受け皿

- こども家庭庁の概要ページでは、放課後児童クラブの設置・運営主体として `市区町村、社会福祉法人、保護者会、運営委員会、その他の者` が示されている。
- したがって、国費の出口は一律の単一事業者ではなく、自治体の実施方式に応じて公営運営費、委託先法人、改修工事、ICTベンダー、巡回支援人材などに分かれる。
