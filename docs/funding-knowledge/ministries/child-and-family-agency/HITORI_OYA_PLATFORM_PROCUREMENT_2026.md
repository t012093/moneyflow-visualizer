# ひとり親家庭に対するプラットフォーム構築事業の公募要件・運営主体メモ

## 結論

- `令和8年度` の `ひとり親家庭に対するプラットフォーム構築事業` は、ひとり親家庭向け支援情報の `収集・整理`、`ポータルサイトの作成・運用`、`広報啓発` をまとめて担う事業として公募されている。
- `2026年1月27日` に公募が始まり、締切は `2026年3月4日` だった。
- 公募要領上の上限額は `27,556千円`。
- 応募は `法人格` を持つ団体が前提で、`組織・人員体制`、`経理体制`、`児童福祉分野の知見`、`プラットフォーム構築・運用の実績` が重要になる。
- `令和6年度` の制度説明資料では `27百万円`、`令和8年度` の EBPM 資料では `28百万円` が確認でき、少なくとも複数年度で継続している。
- `2026年3月16日` 時点で、確認できた公式資料ではこの事業の `二次募集` は見当たらない。
- 現在運営中のポータル `あなたの支え` のフッターでは、本事業の `実施主体：朝日新聞社・こども家庭庁補助事業` と明記されている。
- ただし、`2026年3月16日` 時点で、こども家庭庁の公式サイト上では `令和8年度の採択結果一覧` そのものは確認できていない。

## 何をやる事業か

公募要領で示されている中心業務は次のとおり。

- ひとり親家庭に関する支援情報の収集
- 支援情報の整理・集約
- `ポータルサイト` の作成・運用
- インターネット広告等を活用した `広報啓発`

実態としては、現場支援そのものよりも、`情報基盤` と `広報導線` を整えるための事業と読むのが自然である。

## 応募要件

- `法人格` を有すること
- 事業を実施するための `組織` と `人員` を持つこと
- 事業を適切に執行できる `経営基盤` と `経理処理体制` を持つこと
- 反社会的勢力に該当しないこと
- 指名停止等を受けていないこと

共同実施は可能だが、応募は `代表法人1者` で行う整理になっている。

## 対象経費

公募要領で確認できる主な対象経費は次のとおり。

- `印刷製本費`
- `デザイン制作費`
- `広告料`
- `人件費`
- `謝金`
- `旅費`
- `通信運搬費`
- `委託料`
- `使用料・賃借料`

つまり、`Web制作`、`運用`、`コンテンツ整備`、`広告運用` を一体で組める体制が求められている。

## 評価軸

評価基準で見られる主なポイントは次のとおり。

- コンテンツ企画力
- 情報収集・集約・管理方法
- 広報施策の有効性
- 実施スケジュール
- 実施体制
- プラットフォーム構築実績
- 児童福祉分野の知見

このため、`Web制作会社` 単体よりも、`情報運用` と `福祉分野理解` まで含めて示せる事業者の方が相性がよい。

## 継続性

- `令和6年度` の制度説明資料では、`ひとり親家庭等に対するワンストップ相談体制強化事業（プラットフォーム構築事業）` として `27百万円` が示されている。
- 同じ資料では、`2024年11月1日` に情報ポータルサイト `あなたの支え` を開設したことも確認できる。
- `令和8年度` の EBPM 資料では `28百万円` が示され、引き続き `情報収集・整理`、`ポータルサイト作成・運用`、`広報啓発` が主要タスクになっている。

したがって、この事業は単年度のスポット施策というより、`ポータル運営を伴う継続事業` と見るのが妥当である。

## 実運営主体として確認できる範囲

- こども家庭庁の `令和8年度ひとり親家庭に対するプラットフォーム構築事業` 公募ページでは、参考情報として `現在運営しているポータルサイト` が案内されている。
- そのリンク先である `あなたの支え` のフッターには、`本事業はひとり親家庭に対する就業支援プラットフォーム構築事業として実施しています（実施主体：朝日新聞社・こども家庭庁補助事業）` とある。
- 同サイトには `2026年2月20日` 付の更新も掲載されており、現行運営中のポータルであることが分かる。
- このため、少なくとも `現行公開ポータルの実運営主体` としては `朝日新聞社` が確認できる。
- 一方で、`令和8年度の採択結果一覧` や `採択団体公表ページ` は、確認できた公式資料では見当たらない。したがって、`朝日新聞社が令和8年度公募の正式採択先として公表済み` とまでは現時点では断定しない方がよい。

## 読み方

- `参入しやすさ` という観点では、巨大な基幹システム案件よりは軽い
- 一方で、単なるサイト制作ではなく、`情報運用 + 広報 + 行政精算` を含む
- そのため、`制作会社`、`広報会社`、`福祉系NPO/一般社団` の連携モデルが最も現実的である
