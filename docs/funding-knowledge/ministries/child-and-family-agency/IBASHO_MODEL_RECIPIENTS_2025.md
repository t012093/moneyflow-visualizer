# NPO等と連携したこどもの居場所づくり支援の流れ先メモ

## 何が公開されているか

- `令和7年度当初予算` では、`こどもの居場所づくり支援体制強化事業` 全体で `8.8億円` が計上されている。
- 公式 EBPM 資料では、この総額の中で `NPO等と連携したこどもの居場所づくり支援` が `30件` のアウトプットとして整理されている。
- `こどもの居場所づくり支援体制強化事業` のうち `NPO等と連携したこどもの居場所づくり支援（モデル事業）` は、`補助率 10/10`、`1団体・1事業あたり上限 500万円` とされている。
- ただし、`どの団体にいくら交付決定されたか` の一覧は、確認できた公式資料では見当たらない。
- そのため、公式に追えるのは `上限額` と `実際に活用された事例` までであり、個別交付額は未公表として扱うのが安全である。

## 2Dフローとの対応

- アプリの `2D` では、`こどもの居場所づくり支援体制強化事業 8.8億円` を reviewed edge として表示する。
- `NPO等と連携したこどもの居場所づくり支援（モデル事業）` 自体の総額は公開資料から切れないため、専用フローは `支援体制強化事業` 全体にひも付けている。
- `調査ノート` の `2Dフローで見る` を押すと、この reviewed edge にフォーカスする。

## 公式に見える流れ先の分類

### 自治体

- `横浜市` : こどもホスピスに関する啓発活動
- `池田市` : 出張型プレーパーク
- `京都市` : 高校内居場所カフェ
- `千葉市` : 夜間の居場所づくり、生活実態把握
- `鳥取市` : 地域食堂フォーラム
- `北九州市` : プレーパーク開催支援システム
- `三股町` : 閉所状態にある公共施設の活用
- `朝日町` : 美術館を活用した居場所
- `宮崎市` : コワーキングスペースを活用した中高生の居場所

### 民間団体

- `一般社団法人にじーず` : LGBTのこども・若者のオンライン居場所
- `認定NPO法人キッズドア` : 不登校・引きこもり等のこどものオンライン居場所
- `特定非営利活動法人 日本教育再興連盟` : 災害時のこどもの居場所
- `一般社団法人 第3職員室` : 災害時のこどもの居場所、ユースワーク

### オンライン

- `一般社団法人にじーず`
- `認定NPO法人キッズドア`
- `ろう児・難聴児のオンラインコミュニティ事業`

### 被災地支援

- `令和6年3月6日` のこどもの居場所部会資料では、能登半島地震対応として `被災したこどもの居場所づくり支援` の追加募集を行い、`32団体を採択` したと説明されている。
- この追加募集でも `1団体あたり上限500万円`、`国10/10` とされている。
- ただし、`32団体それぞれの名称や交付額一覧` は、確認できた公式資料では見当たらない。

## 読み方

- `どこに流れたか` は、現状では `活用事例` や `採択団体数` までが公式確認できる範囲である。
- `どれだけ流れたか` は、`1件あたり上限500万円` までは分かるが、個別交付額は未公表である。
- したがって、この事業は `自治体` と `民間団体` の両方に流れうるが、金額面は `上限ベース` でしか見られない。
