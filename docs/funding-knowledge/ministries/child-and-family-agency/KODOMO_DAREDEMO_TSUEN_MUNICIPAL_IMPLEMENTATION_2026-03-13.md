# 自治体別の実施状況と委託先

## 概況

- こども家庭庁の実施状況資料では、2025年7月7日時点で `118自治体 / 757か所` が確認できる。
- 受け皿は社会福祉法人、学校法人、公立施設、株式会社、NPO など多様。

## 自治体ごとの見え方

- 神戸市、横浜市、静岡市、京都市では、実施施設一覧や利用案内が公式ページで確認できる。
- 静岡市では、利用料の施設直接払いが明示されている。
- 京都市では、要綱上で委託先施設への支弁が整理されている。

## 別系統の委託

- 広島市では、実施施設への給付とは別に、制度管理運用業務の委託先が公募・公表されている。
- このため、制度資金の主流は `国 -> 市町村 -> 実施施設・事業者` だが、行政運営事務の委託費が別系統でベンダーに流れる場合がある。

- こども誰でも通園制度 令和6年度の実施状況
- 神戸市 こども誰でも通園制度
- 横浜市 こども誰でも通園制度（乳児等通園支援事業）について
- 静岡市 乳児等通園支援事業（こども誰でも通園制度）利用のご案内
- 京都市 京都市乳児等通園支援事業（こども誰でも通園制度）実施要綱
- 広島市 乳児等通園支援事業に係る管理運用業務
