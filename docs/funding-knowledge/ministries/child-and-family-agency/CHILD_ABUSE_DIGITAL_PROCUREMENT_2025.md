# 児童虐待防止対策等のデジタル調達メモ

## 結論

- `児童虐待防止対策等 293億円` のうち、`2025年度` に国の契約公表資料で金額まで確認できるデジタル調達は、少なくとも `7.353467億円` ある。
- `2025年度` の中央契約で確認できる主な受託先は、`富士通`、`NTTデータ`、`野村総合研究所`、`トランス・コスモス` である。
- 自治体の `SNS相談 / LINE相談` は別系統で、`2025年度` に確認できた公募規模はおおむね `1,486万円〜2,572万円` のレンジにある。
- アプリの `2D` では、年度整合を優先して `2025年度` の中央契約だけを exact downstream として接続し、自治体事例は `調査ノート / Structured Facts` で保持する。

## 2024年度から見た連続性

- `2024年度` にも同種の中央契約が確認できる。
- `SNS全国一元システム運用・保守` は `267,878,600円` で `富士通株式会社`。
- `AI全国統一ツール 開発・テスト` は `433,400,000円`、`AI全国統一ツール 運用・保守` は `197,670,000円` で、いずれも `株式会社NTTデータ`。
- `AI工程管理支援` は `114,400,000円` で `株式会社野村総合研究所`。
- `LINEプッシュ通知等` は `10,026,500円` で `トランス・コスモス株式会社`。
- したがって、この領域は `単発` ではなく、`中央システムの継続運用・改修` として複数年度で回っていると読むのが自然である。

## 読み方

- `児童虐待防止対策等 293億円` は制度全体の reviewed 予算であり、ここで確認できる `7.353467億円` はその中の `中央デジタル調達の一部` である。
- 地方自治体の `SNS相談 / LINE相談` は、同じ政策領域に属するが、`国の293億円からそのまま自治体案件へ一直線に流れた額` とまでは一次資料だけでは言えない。
- そのためアプリでは、`2025年度` の exact で確認できる中央契約だけを `2D` の下流に接続し、自治体事例は `調査ノート / Structured Facts` に留める。

## 今後の調達

- `令和8年度` のこども家庭庁調達ポータルでは、`要保護児童等に関する情報共有システムの更改`、`AIを活用した全国統一ツールの運用・保守` など、次年度案件の公告予告が確認できる。
- ただしこれは `2026年度` の話なので、`2025年度` の 2D フローには直接つないでいない。
