# 神戸市こども誰でも通園制度 2025

## 結論

- 神戸市の `令和7年度予算説明書` では、保育振興費の内数として `こども誰でも通園制度 137,500千円` を確認できる。
- 2025年5月21日の神戸市公式発表では、2025年7月1日時点で `35施設` が実施施設として公表されている。
- 実施事業者募集要項では、施設向け補助単価として `0歳 1,300円/時間`、`1歳 1,100円/時間`、`2歳 900円/時間`、賃借料補助 `229,000円/月上限`、改修費補助 `3,000,000円上限` が示されている。

## 予算

- 神戸市の `令和7年度予算説明書（こども家庭局）` では、`保育振興費 (8) こども誰でも通園制度 137,500千円` と記載されている。
- 同じ資料の施策説明ページでは、`こども誰でも通園制度の実施 146,524千円`、`23施設 -> 45施設` とも記載されている。
- 項目粒度が異なるため、アプリの reviewed edge では、事項別の予算説明書に載る `137,500千円` を採用する。

## 制度運用

- 神戸市の制度ページでは、2025年度の利用料を `300円/時間` と案内している。
- 対象は、市内在住で生後6か月から2歳まで、幼稚園・保育所・認定こども園等に在籍していない児童。
- 2026年3月5日更新の制度ページでは、神戸市の実施施設は `44施設` に拡充されている。

## 補助ルールメモ

- 基本単価は `0歳 1,300円/時間`、`1歳 1,100円/時間`、`2歳 900円/時間`。
- 加算は `障害児 400円/時間`、`要支援家庭 400円/時間`、`医療的ケア児 2,400円/時間`。
- 賃借料補助は `1事業所1か月 229,000円` が上限。
- 改修費等補助は `1事業所 3,000,000円` が上限。

## 認可外保育施設の参加要件メモ

- 制度上は、認可外保育施設も実施場所になりうる。
- ただし `認可外保育施設指導監督基準` を満たしていることが前提で、基準を満たさない施設は対象外。
- そのうえで、市町村から `乳児等通園支援事業` の認可を受ける必要がある。
- 設備面では、年齢区分に応じて `乳児室 / ほふく室 / 保育室 / 遊戯室 / 便所` 等が必要で、面積基準もある。
- 職員配置は一般型で `0歳児 おおむね3:1`、`1-2歳児 おおむね6:1`。職員の半数以上は保育士だが、最低2人は必要。
- 社会福祉法人や学校法人以外の事業者は、経済的基礎、社会的信望、役員・幹部の知識経験なども審査対象になる。
- したがって、制度全体では認可外施設も参加可能だが、神戸市の35施設のように既存の保育所・認定こども園・幼稚園が中心になりやすい。
