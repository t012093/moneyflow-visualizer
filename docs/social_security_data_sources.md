### 2-2. 医療費の流れ先（推定内訳）

上記の国民医療費約46.7兆円のうち、**国庫負担分（一般会計歳出ベース）は約12.2兆円**です。
残りは健康保険料（事業者＋被保険者負担）や患者自己負担で賄われます。

```
医療給付費（国庫12.2兆円）
  ├── 病院・診療所（入院＋外来） … 約8.5兆円（69%）
  ├── 薬局（調剤薬局チェーン）  … 約2.1兆円（17%）
  ├── 歯科医院             … 約0.8兆円（7%）
  └── 製薬企業・医療機器メーカー … 約0.8兆円（7%）
```

### 3-2. 介護費の流れ先（推定内訳）

国庫負担分（一般会計ベース）は約3.7兆円。残りは介護保険料で賄われる。

```
介護給付費（国庫3.7兆円）
  ├── 訪問介護事業者（ヘルパー派遣） … 約1.1兆円（30%）
  ├── 特別養護老人ホーム（社福法人） … 約1.1兆円（30%）
  ├── 通所介護（デイサービス）    … 約0.7兆円（20%）
  └── その他（福祉用具・住宅改修等） … 約0.7兆円（20%）
```

## 6. データ取得方法

### e-Stat API
- **統計名**: 社会保障費用統計（国立社会保障・人口問題研究所）
- **URL**: https://www.e-stat.go.jp/stat-search/files?page=1&layout=datalist&toukei=00450032
- **形式**: Excel / CSV
- **更新頻度**: 年次（通常翌々年7月に公表）

### 厚生労働省 オープンデータ
- **国民医療費**: https://www.mhlw.go.jp/toukei/saikin/hw/k-iryohi/
- **介護給付費等実態統計**: https://www.mhlw.go.jp/toukei/saikin/hw/kaigo/kyufu/
- **形式**: Excel / PDF

### こども家庭庁
- **予算概要**: https://www.cfa.go.jp/policies/budget/
- **形式**: PDF

### 財務省
- **一般会計 歳出概算**: https://www.mof.go.jp/policy/budget/budger_workflow/budget/
- **形式**: PDF / Excel

## 7. 注意事項

1. **国庫負担 vs 保険給付総額**: 当可視化では「一般会計からの歳出（国庫負担分）」を
   追跡対象としています。保険料や自己負担を含む「総給付費」とは異なります。
2. **年度差異**: 統計公表のタイムラグにより、医療費（R4確定値）、介護費（R5速報値）、
   予算（R6当初予算）のように年度がずれている場合があります。
3. **USD換算**: 便宜上 1USD = 150JPY で計算しています。
